# Syamna Quran

**Syamna Quran** is a premium, modern digital worship companion for Muslims. Built with a focus on aesthetic excellence and spiritual serenity, it integrates Al-Quran, Hadith, Prayer Times, and more into a unified "Dark Tech" experience.

## 🚀 Key Features

- **🕋 Al-Quran**: High-fidelity reading experience with Tafsir and multi-language translations.
- **📚 Hadith Library**: Trusted collections of Prophet Muhammad's (PBUH) sayings.
- **✨ Asmaul Husna**: Interactive exploration of the 99 Names of Allah.
- **⏰ Prayer Times**: Precise, location-based prayer schedules.
- **🤲 Doa & Dhikr**: Comprehensive library of daily supplications.
- **📈 Progress Tracking**: Integration with Quran Foundation for habit monitoring.

---

## 🛠 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: Tailwind CSS with custom "Dark Tech" design system.
- **Animations**: Framer Motion.
- **State/Data**: TanStack Query.
- **API**: Integrated with Quran Foundation API via OAuth2.

## 🏁 Getting Started

First, install dependencies:

```bash
bun install
```

Then, run the development server:

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
